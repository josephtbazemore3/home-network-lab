Home Network Setup & Troubleshooting Lab

Project Overview

This hands-on project documents my experience setting up and testing a small home Ethernet network as part of my CompTIA A+ Core 1 certification preparation.

Equipment Used

- Verizon G3100 router
- TP-Link 8-port Gigabit Ethernet switch
- Dell Inspiron 15 3558 laptop running Linux Mint
- Ethernet cables

Tasks Completed

1. Connected the TP-Link switch to the Verizon router using an Ethernet cable.
2. Connected my Dell Linux laptop to port 2 of the switch.
3. Checked the switch's LED indicators to verify active connections.
4. Used the ping command to test network connectivity.
5. Confirmed that all four ping packets were received with 0% packet loss.

Results

Successfully established and verified a working Ethernet connection between my laptop and home network.

Skills Practiced

- Ethernet networking
- Router and switch connectivity
- Network troubleshooting
- Linux command-line tools
- Connectivity testing
- Basic CompTIA A+ networking concepts

What I Learned

I gained practical experience connecting network devices, interpreting switch activity indicators, and verifying network connectivity using command-line tools.
